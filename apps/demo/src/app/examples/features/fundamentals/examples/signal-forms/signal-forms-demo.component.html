Bridging classic Reactive Forms to SignalTree state. Angular has no FormControl.connect(signal) API, so this bridges manually — an effect() pushes the signal into the control and valueChanges pushes the control back into the signal — using toWritableSignal() to convert slices. Want signal-native forms instead? See signalForm() from @signaltree/ng-forms on the /signal-forms page.

📄 Example 1: Leaf Signals

Leaves are WritableSignal<T> — bridged manually with effect() + valueChanges

effect(() => control.setValue(tree.$.personal.firstName()))
effect(() => control.setValue(tree.$.personal.lastName()))
effect(() => control.setValue(tree.$.contact.email()))
Tree State: 
{{
            {
              firstName: profile.$.personal.firstName(),
              lastName: profile.$.personal.lastName(),
              email: profile.$.contact.email()
            } | json
          }}

🔄 Example 2: Object Slice

Slices are NodeAccessor<T> and need toWritableSignal()

const personalSignal = toWritableSignal(tree.$.personal);
effect(() => formGroup.patchValue(personalSignal(), { emitEvent: false }));
formGroup.valueChanges.subscribe(v => personalSignal.set(v));
Personal Slice: 
{{
            {
              firstName: profile.$.personal.firstName(),
              lastName: profile.$.personal.lastName()
            } | json
          }}
