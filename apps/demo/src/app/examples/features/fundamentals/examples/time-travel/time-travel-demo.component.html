Time Travel Demo

Time Travel allows you to undo and redo state changes, navigate through your application's history, and replay user actions. Perfect for debugging, testing, and providing undo/redo functionality.

How It Works

  1. Automatic Tracking: Every state change is recorded in history
  2. Navigate History: Move backward and forward through state snapshots
  3. Jump to State: Click any history item to instantly restore that state
  4. Undo/Redo: Built-in undo and redo functionality
  5. Quick Test: Click "Generate Sample Actions" to see time travel in action instantly!

Everything above is plain leaves, and undo has always worked for those. Markers were a different story. Until 14.0.0 a snapshot captured a marker's API surface instead of its state, so an undo left the marker at its post-change value and reported success — landing you in a state that never existed.

Measured before the fix: n=3 rows=3 → undo → n=2 rows=3 . The counter rolled back; the collection did not; nothing said so. Add people, change the job status, edit the profile, then undo — all three roll back together now.
