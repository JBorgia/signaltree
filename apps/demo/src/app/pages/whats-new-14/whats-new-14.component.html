Time travel

Without pause, a bulk import writes a hundred history entries and the user's next undo reverts one row of it. Bulk import adds 25 rows inside pauseRecording() / resumeRecording() — one step, not twenty-five.

canUndo() is reactive as of this release. It read a plain number before, so computed(() => tree.canUndo()) cached false forever and a zoneless app's undo button never enabled. These buttons are bound to it directly.

ST2026 — the inline-predicate trap, measured here

where and find memoise per predicate identity. An inline arrow in a template allocates a new one every change-detection cycle, misses the cache, and re-filters the whole collection. It is not a leak — the cache is a WeakMap — which is exactly why it needed a diagnostic: nothing grows, nothing errors, the app is just permanently slow.
