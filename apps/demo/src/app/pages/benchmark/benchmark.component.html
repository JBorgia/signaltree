Key insights

Priming closes the model-tier gap

Cold scores are roughly tier-agnostic (range 44–63). Primed scores are also tier-agnostic (range 78–100).

Primed Haiku 4.5 (97) outscores cold Sonnet 4.6 (44) by 2.2×. Your code agent on a cheap model still writes correct SignalTree.

Four of six agents hit the ceiling

Primed Claude, GPT-5.4, Perplexity Sonar Pro, and GPT-5.4-mini all scored 100/100. Only Gemini (91, long-context dilution) and Haiku (97, one residual hallucination class) are still short of it.

Adding myths.md now boosts accuracy — reversed from v10.2

In v10.2, llms.txt + myths.md (87%) scored worse than llms.txt alone (91%) — context dilution. After the doc-patch quadrilogy, that flipped: llms.txt alone now scores 95%, and adding myths.md pushes it to 98%.

Gemini shows the reversal most sharply: it regressed 83 → 64 with myths.md in v10.2, and now improves 78 → 91 with myths.md in v10.3.3. Recommendation flip: ship myths.md alongside llms.txt as priming.

The discoverability surface ships with npm

As of v10.2, llms.txt ships in the @signaltree/core tarball. After npm install, retrieval-aware AI agents find node_modules/@signaltree/core/llms.txt automatically.

The README also leads with the disambiguation table — rendered on npmjs.com and indexed by every AI tool that crawls node_modules READMEs.

What's still wrong (residual failure modes)

The 2pp gap between primed-SignalTree (98) and ceiling (100) lives in this one residual marker-method hallucination. The v10.2 disambiguation table eliminated the package/import class entirely; the v10.3.3 doc-patch quadrilogy eliminated 6 of the remaining 8 marker-method confusions.

Methodology

  • Cold mode: standard prompt + "you are a senior Angular engineer" system message. No SignalTree context.
  • Primed-llms.txt: the 13.5KB llms.txt injected as an additional system message.
  • Primed-llms.txt + myths.md: both files concatenated as priming context.
  • Reproducibility: all prompts as YAML in scripts/ai-codegen-benchmark/prompts/, temperature 0, model versions logged per cell.
  • Scoring: idiomatic-pattern match + import-resolution against real-package allowlist + marker-method validity against actual API surface. Equal-weighted average.

The marker-method validator catches the dominant primed-run failure mode (hallucinated method names) that text pattern-matching alone misses. Compile + behavior testing in TestBed remains deferred to a future run.

Reproduce it

The full benchmark is open and reproducible. One OpenRouter API key, ~$15 and ~30 minutes of wall-clock for a full quarterly run. 

git clone https://github.com/JBorgia/signaltree
cd signaltree
export OPENROUTER_API_KEY=sk-or-...

# Cold
node scripts/ai-codegen-benchmark/runner.mjs --include-tier-comparison

# Primed
PRIMING_CONTEXT_FILE=apps/demo/public/llms.txt \
  node scripts/ai-codegen-benchmark/runner.mjs --include-tier-comparison

# Aggregate
node scripts/ai-codegen-benchmark/aggregate.mjs \
  scripts/ai-codegen-benchmark/results/* > RESULTS.md
